Linear Regression on Housing Dataset

This project applies a Linear Regression model to predict house prices based on various features.

🔹 Workflow
Imported and explored the dataset using pandas
Preprocessed data by handling missing values and encoding categorical variables
Split dataset into training and testing sets (80:20)
Trained a Linear Regression model using sklearn
Evaluated performance using MAE, MSE, and R² score
Visualized the regression relationship for a key feature
Interpreted model coefficients to understand feature impact
🔹 Results
The model captures relationships between input features and house prices
Evaluation metrics provide insight into prediction accuracy and model fit
🔹 Conclusion

Linear Regression provides a simple and interpretable baseline model for house price prediction, with coefficients offering clear insights into feature importance.
